# Scoped analytical engineering screens

The planner needs actionable calculations beyond sunlight and battery charge, while the bundled regional/global data cannot measure landing-gear hazards or qualify a spacecraft.

Seven optional pure analytical screens accept explicit finite inputs, compute SI-valued results and retain their source, assumptions and unresolved scope. Empty data remains unknown; known violations survive other missing inputs. A successful screen is conditional. Site/date/dataset scope changes invalidate supplied measurements until deliberate reconfirmation. Shared assessment, scenario links, comparisons and decision exports retain the same canonical inputs.

Qualified external reports remain separate required evidence. Landing readiness additionally requires navigation/guidance. Base-specific disciplines are configurable rather than assumed applicable to every sortie. This preserves an auditable path from a useful calculation to the evidence still needed, without converting a simplified model into operational approval.

Compatibility: optional schema2 fields preserve older records without engineering inputs. Numerical/constraint meaning is identified as planning-4. Old externally reported assessments require reassessment when model identity changes. No database or new numerical package is introduced. Inputs and model output can still be used offline.

Validation includes analytical boundary/overflow tests, strict parsing, stale-scope behavior, sharing/export round trips and integrated browser checks. Physical qualification, independent terrain/frame validation and actual screen-reader evaluation remain independent gates.
