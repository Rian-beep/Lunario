# Math-engine traceability

This is a descriptive map of the installed engines, not a second calculator or a scientific acceptance report. See [Data pipeline](DATA-PIPELINE.md) and [Models](MODELS.md). Equations and symbols below are hand-authored native MathML; no TeX runtime, new dependency or generated registry is used. Angles are radians in relations; source and interface degrees, catalog kilometres and model Wh/h are called out explicitly. Source-to-input alignment remains uncertain. Fresh audit status is supplied separately.
