## Performance evidence

The same actual-app harness, same Radeon renderer, three fresh contexts per artifact and quiet sequential runs measured median worst frame gap during the four seconds after initial Moon readiness at **400.0 → 66.6 ms**. Thrust-edit feedback medians were **58.6 → 54.0 ms**. First usable Moon times after clicking preview were essentially unchanged: **1,320.4 → 1,319.3 ms**. The intentional three-second introduction is separate. These local/warm-OS-file observations do not establish cold internet, mobile or universal frame rates. The isolated moving-camera decode experiment independently supports the image-upload diagnosis and preserves identical rendered pixels.

The final hosted receipt records roughly 1.31 MB of initial JavaScript and a 394 KB gzip-6 estimate; these are byte accounting, not measured CDN encoding or latency. The generated offline file remains below GitHub's 100 MiB file limit. Obsolete generated chunks were pruned; new deferred features account for total bundle changes.
