# Neutral lunar atlas appearance

All lunar imagery uses shared `neutral-linear-rec709-v1` presentation. Encoded sRGB source channels are decoded to linear light, combined using Rec.709 coefficients (0.2126, 0.7152, 0.0722), then encoded back to sRGB. This removes the whole-Moon texture's brown cast without applying a CSS filter to the map, its labels or its coloured site markers. Matching 3D shaders must apply these coefficients after Three's sRGB texture decode and disable tone mapping for the default Atlas mode. Exposure or ACES mapping must not add a different transfer function to only one view.

The 2D maps cache one neutral canvas per loaded image in a WeakMap. Conversion happens when source imagery becomes ready, not once per animation frame. Source dimensions, pixel positions, geographic extents and alpha remain unchanged. A 16-bit linear-to-sRGB lookup contributes at most one output-code quantisation difference from the exact transfer. The global atlas, polar LOLA hillshade, bundled WAC/NAC patches and optional online NAC tiles all pass through this image-only conversion. Markers, labels, graticules and scientific overlays are drawn afterwards. No imagery assets or numerical terrain products are rewritten.

Default polar lighting wash is off; explicitly enabled epoch overlays remain separate. The shared neutral atlas does not make the sources physically identical: source acquisition shadows, phase, coverage, projection and resolution still differ. It is not an albedo estimate or a new measured terrain product. NASA original globe/local 3D integration is owned by the separate scene worker and consumes the same constants. Earth, Sun and spacecraft retain their own colours.

Validation: four targeted tests cover standard transfer breakpoints and roundtrip, primary-colour reference luminance, all 256 gray levels and alpha/idempotence, and malformed pixel buffers. Full TypeScript and targeted ESLint pass. The combined four-view rendered pixel hue/stability audit awaits the parent's coordinated preview; no new-build browser pass is claimed here yet. `data-lunar-appearance` and `data-lunar-atlas-ready` on each 2D canvas expose presentation/asset readiness for that audit, independently of marker styling.
