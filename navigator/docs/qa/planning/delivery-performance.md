# Delivery performance measurement

`node /absolute/path/scripts/verify-delivery-performance.mjs --base-url http://127.0.0.1:4317 --output /tmp/solarreach-delivery-performance-http` measures the existing preview. For an immutable standalone use `--file /absolute/path.html --offline`. Run from the source repository whose actual production modules should be bundled into the measurement bridge. The script never builds/starts the app, downloads a browser, changes a user profile, throttles the CPU or substitutes another numerical engine.

The report identifies OS/architecture/CPU/RAM, Chrome version, viewport, UTC, served HTML or file byte/hash identity, every bundled production-source input SHA-256 and bridge SHA-256. Catalog and manifest hashes cover JSON.stringify of the actual parsed/injected values; they are explicitly distinguished from source-file byte hashes.

App-ready spans navigation until the named workbench is visible. 3D-ready spans the real 3D button action until canvas, original NASA Moon and lander status are ready and no destination terrain preparation is active. The app-ready timestamp does not imply every optional texture has loaded. Separate fresh browser contexts measure UI/3D and search; OS/disk caches are not cleared, so these are observations rather than statistically stable cold-start benchmarks.

The browser bridge is an esbuild IIFE of actual `lib/planning-search.ts` and dependencies. It loads the actual catalog/manifest plus demonstration baseline, chooses one prepared site and exactly1000 hourly starts, each a complete336h stay, retaining20 results. It records total/evaluated/outside and all outcome counts, progress timestamps, real timer/rAF heartbeats and maximum timer gap. A second job aborts after nonzero progress; it must reject AbortError before1000 candidates, with measured abort response. These assertions prove bounded cooperative scheduling, not a universal frame-time guarantee; one synchronous assessment cannot be preempted. There is no invented numerical speed cutoff. Actual measurements remain pending the coordinated final audience build until recorded below.
