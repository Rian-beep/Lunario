# Browser zoom evidence — 2026-11-14

The verifier now measures actual Chrome layout zoom in dedicated temporary persistent profiles. It never opens the user's profile or foreground browser. Chromium's [ChromeZoomLevelPrefs implementation](https://chromium.googlesource.com/chromium/src/+/main/chrome/browser/ui/zoom/chrome_zoom_level_prefs.cc) reads partition-specific default zoom levels; [preference names](https://chromium.googlesource.com/chromium/src/+/main/chrome/common/pref_names.h) identify `partition.default_zoom_level`. The default storage partition key is `x` (hex encoding of the empty relative path). Zoom level is logarithmic: log(factor)/log(1.2). This is an internal Chromium preparation mechanism, so the script verifies its effect rather than assuming Chrome honors it.

A newly created `/tmp/solarreach-verify-zoom-*` profile receives only its own Default/Preferences before launch. Two independent headless persistent contexts use the existing Chrome executable and an unchanged 1600×1080 outer window. No viewport or device-scale emulation is applied (`viewport:null`). The script checks observed devicePixelRatio doubles, CSS inner width halves, outer width remains fixed, visualViewport.scale stays 1, physical screenshot width remains fixed, and document width does not overflow. It also tests body Space playback, unrelated button Space activation, and guide Escape at the verified 200% zoom. Both contexts close and temporary profiles are removed even on failure. Failure retains the manual zoom gate.

Observed probe values: 100% DPR1 / innerWidth1600 / outerWidth1600 / visual scale1; 200% DPR2 / innerWidth800 / outerWidth1600 / visual scale1. Playwright's normal screenshot normalized the zoomed image to 800 CSS pixels even with scale=device. Direct CDP `Page.captureScreenshot` surface capture produced the actual 1600-pixel image without changing zoom; the verifier records PNG physical dimensions. CDP is used for capture only, never pageScaleFactor. Artifacts are `planner-browser-zoom-100.png` and `planner-browser-zoom-200.png`, plus measurements in report.json.

[Chrome tabs.setZoom](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-setZoom) is a browser zoom API, but [Playwright's extension documentation](https://playwright.dev/docs/chrome-extensions) says branded Chrome/Edge removed command-line sideload flags and extensions need persistent Chromium contexts. No extension, new Chromium download or dependency was introduced. Preference-based isolated preparation was verified against the already installed Chrome instead.
