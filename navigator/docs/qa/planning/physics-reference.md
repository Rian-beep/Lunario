# Physics reference

`PhysicsReference({mode: 'public' | 'teach' | 'plan'})` is an inline, initially collapsed, dismissible reference. The parent may place it in every mode; Public collapses equation detail, while Educator and Planner expand the selected topic's relations. Dismiss/restore and the topic selector are local UI state and never alter scenario state. No fixed overlay, network requests, new solver or assessment verdict is introduced.

The seven-topic catalogue in `lib/physics-reference.ts` covers inertial orbit geometry and ideal transfers; translational powered descent, mass flow, hover and TRN dispersion; contact/soil/rocks/plumes; illumination/shadows; thermal/electrical/fission/ISRU/habitat/robotics; RF/network/rendezvous/abort; and traverse/consumables/science utility. Unicode notation includes symbols, SI units, frames and limiting assumptions. Every topic separates current model boundaries, user inputs and required external evidence. NASA source links are topic-specific, checked against official NASA/JPL material on 14 November 2026. Source links support the domain and model limitations; they do not certify the analytical examples or the application.

The supplied AI text is not a source of historical performance limits. Its universal polar elevation rate, fixed slope/soil limits, government utility weights, asserted landing probability, exact guidance polynomial and hover-time equivalence are corrected explicitly. In particular, ideal local hover at 1.62 m/s² for 90–120 s costs approximately 146–194 m/s of gravitational impulse per mass. Poisson zero-hit probability is labelled an uncertified toy model with restrictive assumptions, not landing survival. Free-return turning-angle algebra cannot establish Earth return/entry feasibility. No copied Apollo constants become defaults or requirements.

Validation: focused catalogue tests check evidence states, dimensional/frame definitions, NASA source hosts, coverage of missing inputs and explicit rejection of the problematic claims. Targeted ESLint and TypeScript are run separately; no browser/server/build is started by this workstream. Parent integration must verify placement, dismissal/restore and selected-topic readability in all three modes. This module intentionally adds no duplicate engineering/flight calculators.

The visual followup uses the existing warm paper/olive application tokens for surfaces, text, borders, links and focus indicators. `scripts/verify-physics-reference.mjs` accepts `--base-url URL` or `--file PATH`, optional `--offline`, and required `--output DIR`. It opens all seven topics in each audience mode, checks equation disclosure defaults, units/frame/evidence labels and official source links, then exercises dismissal/restoration and captures screenshots. Syntax and ESLint checks pass; integrated browser evidence is pending the coordinated preview marker and is not yet claimed.
