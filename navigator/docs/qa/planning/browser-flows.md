# Whole-planner browser flows

Run `node scripts/verify-planning-flows.mjs --base-url http://127.0.0.1:4317 --output /tmp/solarreach-planning-flows-http` against an integrator-built preview. To test the final standalone artifact: `node scripts/verify-planning-flows.mjs --file /absolute/path/solarreach-navigator.html --offline --output /tmp/solarreach-planning-flows-offline`.

The verifier uses installed playwright-core and a dedicated headless Chrome context at 1600×1000; it never attaches to a personal browser or starts/builds the app. Set PLAYWRIGHT_CHROMIUM_EXECUTABLE to an existing Chrome binary if necessary. No dependencies are installed. Each flow records its result and a screenshot; failures capture a screenshot and retain later independent attempts. report.json includes page errors and HTTP errors. Real JSON downloads and teaching records are retained in the requested output directory.

Checks cover Planner assessment dismiss/minimize/restore; independent instrument heights and deployment inputs persisted to localStorage; Space/Escape on a new summary preserving paused environmental playback; 31 complete daily mission starts; controlled +1-day candidate preserving all nondate inputs; exact saved baseline/candidate pair; configurable comparison metadata, changed assumptions and exact opening; real decision-package export/import; explicit sensitivity cases, invalid input and cancellation; Educator prediction/single-variable record/reset preserving saved evidence; audience switching retaining physical inputs; and actual NASA equipment ready status. Offline mode rejects HTTP traffic rather than assuming embedded assets work.

This script is a workflow regression check, not a full accessibility or scientific certification. Screenshot readability, screen-reader announcements, unknown historical-site messaging, real 200% browser zoom, and behaviors not explicitly passed in report.json must be assessed separately. A script prepared before a build is not evidence that the app passed it.
