# Audience depth and visible notation

`AudienceContextPanel({mode, state, assessment, siteName?})` is inserted by the parent at the top of the inspector. Public defaults to three compact questions about darkness/storage, communication gaps and controlled date/place comparisons. Equations remain optional there. Educator displays three actual model relations immediately, including solar generation, Wh battery flow and spherical Sun direction. Planner displays current outcome, required unknowns, known failures, independent subsystem heights, reserve margin, geometric outage/limit, first known failure bracket and data/model identity. Its next steps point to controlled full-stay comparisons and matching missing evidence; no approval or readiness score is invented.

The shared variable explorer is secondary and collapsed by default. It exposes Unicode symbols, named quantities, units, equations, physical meanings, measured quantities, intuition and limits. Recurring Greek letters retain explicit context: α is array bearing, γ is commanded thrust pitch rather than a measured velocity angle, and η is efficiency. Latin symbols such as E, A, m, T and Isp are retained where appropriate. Energy equations explicitly use Δt in hours with Wh, and state 1 Wh = 3600 J. Degree-valued controls are converted to radians for trigonometry. Vector acceleration/direction notation is distinguished from scalar maneuver budgets. All seven engineering-screen domains use existing descriptor intuition and units; no universal safe ranges are generated.

Every matching existing Info dialog gains a notation block through `resolveVariableNotation(label)`. Existing public intuition comes first; its notation is collapsible. Educator/Planner notation opens by default. Hover, focus, pinning, Escape, Tab, scroll and the existing `extra` API are retained.

The Educator panel records a local prediction and an exact baseline input snapshot, then shows actual tracked input differences and reserve/outcome changes from the supplied shared assessment. It warns when multiple inputs changed and never guarantees that changing latitude/longitude helps. This local check does not replace saved scenarios or the persistent teaching notebook. It neither mutates scenario inputs nor recomputes physics.

Validation: four tests check expected standard symbols and unit distinctions, complete unique notation records and all seven engineering descriptor domains. Full TypeScript and targeted ESLint pass. Rendering/readability, inspector placement and Info keyboard behavior await the parent's combined audience build; no browser coverage of this new panel is claimed yet.

Actual control-label aliases also cover Incident flux, Tilt from horizontal, Panel azimuth, Usable capacity, Initial charge, Reserve threshold and Time (UTC). Initial and reserve charge are separate quantities. Engineering notation supplies a complete Info explanation when no older glossary entry exists; unrelated narrative labels still do not get invented symbols.

## Guided Public interpretation and complete flight/radio fields

Public context now starts with a brief, constraint-driven explanation: a known power failure, communications failure, missing evidence, conditional result or assessed pass gets an appropriate plain-language reason and next comparison. Known failures remain visible alongside missing evidence; unknown sites are neither rejected nor promoted. Optional failed screens cannot override the required assessment outcome. Guidance groups existing constraint states without recomputing numerical results or exposing raw technical row dumps. It explains the low polar Sun, terrain blockage, date/stay tradeoff and the difference between Earth visibility and usable communications. Larger arrays, storage or changed arrivals are proposed tests rather than guaranteed fixes.

Notation now covers every displayed flight input and all nine optional radio-link inputs, plus the independent antenna elevation mask. New definitions distinguish signed vertical flight speed from contact-speed magnitude, flight preview seconds from surface-stay hours, RF transmit power from total bus demand, receiver noise temperature from weather, and frequency GHz from equation Hz. Noise density, free-space spreading, received power, bit-rate penalty and finite-burn mass flow use the same model relations and units as the implementation. Greek letter names (eta, beta, phi, lambda, gamma, chi, tau, theta and others where used) appear in meanings; Latin quantities retain their proper symbols. Main context copy is 14 px and labels 13 px.

Validation: **12** focused tests cover notation completeness/units and Public interpretations, including known failure plus missing evidence, optional failure, communications-only recommendations and explicit additional unmet-demand failure. Full TypeScript and targeted ESLint pass. Browser validation still requires the combined audience build; earlier four-view and DSN reports do not certify this later UI revision.

The actual Eb/N₀ estimate, required decoding threshold and configured minimum link margin have separate notation records. Current flight playhead seconds are separate from the requested preview span. These distinctions prevent a requirement or a display clock from being described as a computed physical result.
