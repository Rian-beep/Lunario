# Compact rise/set cards

Two parallel, shared-row cards replace the long visibility-change sentences. Sunlight uses a filled amber disk; Earth visibility uses a blue ring. Each card separates its event name, countdown and UTC date/time window. The existing five-state bar and textual percentage legend remain available, with unknown coverage separate from known zero visibility.

AudienceContext controls presentation; the existing planner boolean remains supported. Public uses approximate human-scale countdowns (~18 days and ~3 days for the 439–440 h and 65–66 h brackets). Educator and Planner retain compact model brackets (18d7–8h and 2d17–18h). Relative fractional-hour brackets round outward to minutes, never narrowing the underlying interval. Same-day windows display one date and a short UTC clock range. Midnight, month and year crossings retain both dates. Unknown data and no-change-within-stay states have explicit text and never become zero countdowns.

Sampling, exact relative model hours, intuition, antenna-mask semantics and the distinction between Earth geometry and an operational radio/ground-station service sit in the existing Info control, reachable by focus, hover and tap. The cards do not change geometry, mission calculations, event boundaries or playback. Subgrid row tracks align card headings, event names, countdowns and dates without competing with any form input.

Validation: eight `tests/windows.test.ts` tests pass, including the original numerical tests unchanged and new presentation fixtures for both requested long brackets, subday and fractional countdowns, midnight/month/year UTC windows and unknown/outside forecasts.
