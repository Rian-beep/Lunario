## Behavior

Broken NASA pieces retain the original normalized metre geometry and kilometre world scale; no pieces are removed from the framing cloud. Original per-piece transformed bounds, including behind-camera corners, define a sphere about the current control target. Existing user pan stays intact.

Only for breakup, render distance is a deterministic C1 upper envelope of the base distance and `1.2 × cloud radius + near`, with a transition band of 10% of base distance. Compact clouds preserve the exact base offset. Larger clouds pull the camera back along its existing viewing ray, leaving the target and orientation unchanged. Existing off-axis projection then fits every corner into the measured visible space between panels.

The numerical-terrain guard samples the candidate camera position with the existing `toGround` path and preserves 2 m camera clearance. If an inward viewing ray enters that sampled sphere, it solves the exit along the same ray and resamples there. This is a camera constraint, not a terrain/physics/contact change. Normal upward Follow does not require this exit correction.

The unexpanded camera position is captured before framing and restored in the render `finally` clause, including renderer failure. Controls, focus travel, mode/reset changes, edits and backwards scrubs therefore never inherit expanded distance from the last frame. True fitted camera position/distance, body radius, geographic readout and clip planes are recorded before rendering; completed-render datasets retain their existing publication timing. Requested focus into an already-broken state uses the same fitting path during asset travel. Pointer picking in Follow/Inspect uses a snapshot of the fitted camera; controls and other views retain their existing base-camera behavior. This keeps pointer rays aligned with the drawn pieces after the base pose is restored.

Occlusion intersects the actual canvas with its host and the CSS-pixel visual viewport, including visual viewport offsets. Panel subtraction then runs in that visible intersection and returns host-relative bounds. Scroll, reflow, viewport resize/scroll and canvas movement invalidate the measurement. A fully offscreen or fully obstructed canvas is `occluded`; empty/nonfinite geometry is `unavailable`. Neither state is a framing pass.
